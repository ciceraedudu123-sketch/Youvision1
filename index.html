Ajuda

Perguntas frequentes

O aplicativo já está disponível para baixar?

O site está preparado para mostrar a versão mais recente quando o APK for publicado em uma Release do GitHub. Até lá, não há instalador público validado.

O YT VISION remove anúncios do YouTube?

Não. A reprodução do YouTube usa o player oficial e pode apresentar anúncios. O aplicativo não altera nem contorna os mecanismos do serviço.

Posso adicionar vídeos de outras fontes?

Sim, desde que você tenha direito de reproduzi-los e forneça uma URL HTTPS direta para um arquivo de vídeo compatível. Links de páginas de streaming não são necessariamente links diretos de mídia.

Como a pesquisa do YouTube funciona?

A pesquisa depende da YouTube Data API v3 e de uma chave de API configurada com segurança no aplicativo. O uso está sujeito às cotas e políticas do Google.

O site é oficial do YouTube?

Não. YT VISION é um projeto independente e não possui vínculo ou endosso do YouTube ou do Google.
